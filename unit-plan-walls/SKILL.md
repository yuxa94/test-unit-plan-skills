# 벽체

## 사용자가 정할 것 (`profile.walls`)

| 항목 | 질문 예 | 관찰(참고만) |
|---|---|---|
| 구조벽 두께 | 외벽 / 세대간벽 / 세대 내 구조벽 각각 몇 mm? | 프로젝트마다 다름(RC 180~250 범위). 구조도면이 있으면 그 값 |
| 칸막이 종류·두께 | 조적(콘크리트벽돌) 또는 경량(석고·스터드)? 두께? | P4 경량 `WAL_DRY`, P3 `stud80` 블록, P6 조적+석고 병용 |
| 마감 두께 | 벽 양면 마감(미장/석고보드) 두께를 벽 몸체에 포함해 그리나? | P6 `AA-WAXM-GYPB` 석고 별도 레이어 |
| 배정 규칙 | 외곽=외벽, 세대경계=세대간벽, 나머지=경량? 예외 벽은? | — |
| 단면 해치 | RC 해치(AR-CONC) 표시? 조적 해치(45° 평행선)? | P3 AR-CONC s0.5, P3/P6 _USER s60 a45 |
| 구조 고정 | 움직이면 안 되는 벽(구조벽·코어벽·샤프트) | — |

`boundary_meaning`(zoning)과 위 두께가 없으면 벽을 그리지 않는다.

## 절차

1. **배정**: `edges` 각각에 assembly를 정한다. 외곽 edge → 외벽 또는 세대간벽(인접 세대/코어 정보로), 실내 edge → 칸막이. 습식(욕실) 경계는 조적/RC 여부를 확인(방수 때문에 경량 불가인 프로젝트가 많음 — 질문).
2. **축선(axis)**: `boundary_meaning`에 따라 정한다.
   - `wall_centerline` / `mc_grid`: edge = 벽 중심선. 양쪽으로 core/2 + 각 면 마감.
   - `finish_face`: edge = 실 안목면. 벽 몸체는 그 바깥쪽(인접 실 방향)으로; 공유 edge 두 개가 벽 두께만큼 떨어져 있어야 한다. 맞지 않으면 보고.
   - `approximate`: zoning 단계에서 사용자 선택을 받은 위치만 사용.
3. **몸체 계산**: 벽마다 축선 ± 두께 사각형을 만들고, 같은 재료끼리 `unit-plan/scripts/rectunion.py`로 합친다(L/T/X 접합 자동 정리). 재료가 다른 벽이 만나는 곳은 우선순위 RC > 조적 > 경량으로, 낮은 쪽 사각형을 높은 쪽 면에서 끊는다.
4. **개구부**: doors/windows가 이미 있으면 `rough_opening_mm` 사각형을 cut으로 넣는다. 아직 없으면 몸체를 먼저 그리고, 문·창 스킬이 끝난 뒤 벽 몸체를 다시 계산하는 작업을 `wall-00N`으로 추가한다(이전 객체는 object-map으로 찾아 교체).
5. **작도** (`upc:run`, 작업 ID `wall-001`…): 재료별 레이어(`wall.concrete` / `wall.masonry` / `wall.drywall`)에 rectunion 루프를 닫힌 폴리라인으로 그린다. 해치는 `outer` 루프 하나 + `parent`가 그 루프인 구멍들을 inner loop로 묶어 `wall.hatch` 레이어에 한 번 만든다. 구멍 루프만 따로 해치하면 세대 내부 전체가 칠해진다. MC/중심선은 `grid.mc` 레이어에 축선을 세대 외곽보다 조금 길게.
6. model.json `walls`(id, edges, assembly, axis, 두께, outline, joins)와 object-map 기록.

## 구현 상태

- 참고 세대 실행기(`unit-plan/scripts/run_reference_unit.py` → `build_walls`)
  - 벽 중심선(`CEN_CON`, `CEN_WALL`)을 벽체선 범위로 자른다.
  - 양쪽 벽 면을 벽체선에서 **자동 실측**한다. RC 중심선은 `CONC` 선을 우선 보고, 한쪽에만 선이 있으면 벽 전체가 그쪽에 있는 것으로 본다. `walls.party_axes`의 세대간벽은 측정된 반쪽을 대칭으로 쓴다.
  - 직교 벽 끝까지 이어 접합을 정리한다.
  - 몸체는 `rectunion.py`로 합치고 재료 우선순위는 RC > 조적 > 경량이다. 개구부는 절단하고, 조적에는 ANSI31 해치를 넣는다.
- 자동 실측은 청주 84A 수동표와 24개 중 20개가 일치했다. 한 중심선에 벽 몸체가 섞인 벽은 `walls.overrides`로 지정한다. 실측 선이 없어 기본 두께가 쓰인 벽은 `issues.walls`에 보고된다.
- 새 조닝(방식 B)에서는 assembly 두께를 프로파일로 받아 같은 몸체 계산을 쓴다. 비직교 벽은 미지원이다.

## 확인

- 각 실 안목 치수 = 축선 간격 − 양쪽 반두께 − 마감, 계산값을 표로 남긴다(치수 스킬이 사용).
- 해치 면적 = 외곽 루프 면적 합과 일치(±1%), 해치가 문 자리를 덮지 않는지.
- 서로 다른 재료 벽 사이에 틈/겹침 없음(rectunion 결과 루프 간 교차 검사).
- `review.json.walls`: 벽 수, 재료별 길이, 미배정 edge, 비직교 벽(현재 도구 미지원 → unresolved).

## 하지 말 것

- 관찰 도면의 두께를 확인 없이 기본값으로 쓰지 않는다.
- 구조벽·코어·샤프트 위치를 바꾸는 제안은 그리지 말고 제안서로 보여준다.
