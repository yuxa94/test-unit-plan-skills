# 조닝 해석

## 입력

- DWG: 닫힌 LWPOLYLINE(실 경계) + 실 내부의 TEXT/MTEXT(실명). 레이어 지정이 있으면 그 레이어만.
- 또는 사용자가 준 표/JSON(실명, 가로×세로, 인접 관계)이나 손스케치 설명.
- 한글 경로 DWG는 ASCII 경로로 사본을 만든 뒤 ObjectDBX로 읽는다(`unit-plan/references/cad-runtime.md`).

### 기존 평면도에서 조닝 만들기

입력이 닫힌 폴리라인이 아니라 기존 세대 평면(블록)이면:

1. `unit-plan/scripts/dump-block.lsp`의 `(upd:dump src block out "~<블록이름>*")`으로 세대 블록을 메모리에서 한 단계 펼쳐 선·부품을 덤프한다(원본 저장 안 함).
2. 실명은 시트에 따로 있는 경우가 많다. 세대 블록 삽입점을 찾아 실명 문자 좌표를 세대 로컬 좌표로 옮긴다. 계단 표시(`UP`/`DN`) 같은 비실명 문자는 빼야 한다. 안 빼면 코어 영역이 "UP"이라는 실이 된다(청주 84B).
3. `scripts/zoning_from_centerlines.py dump.tsv names.tsv out.json [--split …]`로 벽 중심선(`CEN_CON`, `CEN_WALL` 등)을 경계로 실 영역을 채운다.
   - 중심선은 벽보다 길게(-300 등) 그려진 경우가 많다. 스크립트가 벽체 선 범위로 잘라낸다. 이걸 안 하면 발코니 같은 공간이 잘못 쪼개진다.
   - 벽 없는 경계(오픈 LDK, 문 없는 드레스룸)는 `--split`으로 가상경계를 주고 사용자 승인을 받는다.
4. 실명 없는 영역이 원본의 다른 근거(바닥 해치 범위 등)로 어떤 실에 속하는지 알 수 있으면 `--absorb "실명:x1,y1,x2,y2"`로 흡수한다.
   - 사각형 안에 중심이 있는 미지정 셀이 그 실에 붙는다.
   - 떨어진 조각은 `실명-2`, `실명-3`…으로 따로 만든다. 원본 실명이 있는 조각이 원래 이름을 유지한다.
   - 조각을 어떻게 부를지(별도 발코니 등)는 사용자에게 묻는다.
   - 예: 청주 84A 발코니2(`validation-log.md` v008).
5. 결과를 원본 위에 겹친 그림(SVG)으로 보여주고 확정한다. 실명 없는 영역(`unnamed_cells`), 같은 영역에 실명 2개(`unassigned_names`), 외부로 새는 영역(`leaks`)을 같이 보고한다.

## 사용자가 정할 것 (`profile.zoning`)

| 항목 | 이유 |
|---|---|
| `boundary_meaning` | 폴리라인이 벽 중심선인지, 마감면(안목)인지, 대략 배치인지에 따라 벽 오프셋이 달라진다. **미확정이면 벽 단계로 넘어가지 않는다.** |
| `mc_module_mm` | MC 격자에 맞출지, 맞춘다면 모듈 크기 |
| 단위 | INSUNITS가 0이면 알려진 치수 하나로 확인 |
| 외기/세대간/코어 경계 | 어느 변이 외기·세대간벽·코어(계단실/EV홀)에 접하는지. 단열과 벽 구성 선택에 쓰인다 |

## 절차

1. 폴리라인을 읽어 닫힘·자기교차·면적·방향을 검사한다. 열린 경계는 끝점 간격(허용오차 1mm)을 보고하고 임의로 닫지 않는다.
2. 실명을 공간에 하나씩 연결한다(점-다각형 포함). 0개/2개 이상이면 문제 목록에 넣는다. MTEXT 서식 코드는 제거하고 표시 문자열만 쓴다.
3. 실명 정규화: 공백 제거("거 실"→"거실"), `room_aliases` 적용(펜트리→팬트리). 표준 실명 집합과 실 종류는 [rooms](references/rooms.md).
4. 각 공간에 `kind`(room/balcony/wet/service/core/exterior)와 `heated`(난방 여부)를 붙인다. 발코니·실외기실·대피공간은 비난방. 확장형에서 확장된 발코니는 거실/침실과 합쳐지는지 사용자에게 확인.
5. 경계를 선분(edge)으로 쪼개 공유 경계를 한 번만 만든다. 각 edge의 좌/우 공간, 외곽 여부를 기록한다. 겹치거나 틈이 있으면(허용오차 초과) 문제로 보고.
6. 기둥·PD·샤프트·코어벽 같은 고정요소는 `fixed`로 분리한다.
7. `boundary_meaning = approximate`이면 MC 모듈 스냅과 벽 위치 제안을 그림(SVG/HTML)으로 보여주고 선택을 받는다.

## 출력

- `model.json`: `unit`, `spaces`, `edges`, `fixed`
- `review.json.zoning`: 공간 수, 실명 매칭 결과, 열린/겹친 경계, 미해결 질문
- CAD에는 그리지 않는다(입력 사본은 `input/`에 보관, 원본 경로·해시 기록).

## 하지 말 것

- 실명이 없는 공간에 이름을 지어 붙이지 않는다(질문).
- 대략 조닝을 벽 중심선으로 간주하지 않는다.
