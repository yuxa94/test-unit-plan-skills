# 마감선·바닥패턴·재료해치

## 사용자가 정할 것 (`profile.finish`)

| 항목 | 질문 예 | 관찰(참고만) |
|---|---|---|
| 마감선 표시 | 벽·단열 바깥에 마감선을 따로 그리나? 두께? | `A-FIN`, `FIN`, `AA-XXXX-FINL`(전 프로젝트) |
| 바닥 패턴 | 욕실·발코니·현관 타일 크기와 방향 | `_USER` 간격 300, 0°+90°(P4, P6), `NET`(P1) |
| 방수 표시 | 평면에 방수 범위 표시? | `CROSS` s6~8 (단열·방수 평면, P1/P3/P6) |
| 재료 해치 표 | 재료별 패턴·축척·각도 | `unit-plan-standards/references/layer-roles.md` 기본안 |
| 기준점 | 타일 격자 시작점(실 모서리/중앙/문 쪽) | — |

## 절차

1. 실마다 마감 루프 = 공간 경계에서 벽 몸체(+단열 띠)를 뺀 실내 영역의 외곽. `rectunion.py`로 실 사각형들(add) − 벽·단열(cut) 계산, 해당 실 쪽 루프를 고른다.
2. 문·창 개구부에서 마감선을 끊을지(문턱 선) 프로젝트 기준을 확인하고 적용.
3. 바닥 패턴: 대상 실 마감 루프를 외곽으로, 그 안의 기구(욕조·UBR 바닥판·샤워부스 등)·PD를 섬으로 넣어 해치. 격자 원점은 `기준점` 규칙에 따라 `vla-put-origin`으로 맞춘다.
4. 방수·재료 해치는 사용자가 지정한 범위에만.
5. 작도(`fin-001`…): 마감선 `finish.line`, 바닥 `floor.pattern`.

## 구현 상태

- `run_reference_unit.finish_loops`: 실 다각형에서 벽·단열을 뺀 안목 루프를 그린다(0.3㎡ 미만 조각 제외). 루프는 문·주방 배치의 안목 판정에도 쓴다.
- 바닥타일: config `tiles`에 적은 실에 `_USER` 300 격자 해치를 넣는다.
- 마감 두께(석고보드 등)·방수 표시·재료 해치 표는 미구현이다. 그래서 안목이 원본보다 넓게 나온다(청주 84A 거실 4520 vs 4420).

## 확인

- 실마다 마감 루프 1개(+섬), 면적 = 안목 면적(치수 스킬과 같은 값).
- 해치가 기구·문 자리를 덮지 않음(섬 처리 확인), 패턴·축척 = profile.
- `review.json.finish`: 실별 안목 면적, 패턴 목록.
