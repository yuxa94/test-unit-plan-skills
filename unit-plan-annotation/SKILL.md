# 실명·주기·도곽

## 사용자가 정할 것 (`profile.annotation`)

| 항목 | 질문 예 | 관찰(참고만) |
|---|---|---|
| 실명 높이·스타일 | 문자 높이(1/50 기준) | 120~150, 레이어 `AA-MKXS`/`실명`/`A12-문자-실명`, 블록형 `실명코드`(P2, P6) |
| 면적 표기 | 실명 아래 면적(m²) 표시? 소수점? | — |
| 레벨 기호 | 욕실·발코니·현관 단차 레벨 표기? | `A-레벨`, `LEVEL-U`, `A13-심볼-레벨` |
| 주기 | 공통 주기 문구 목록 | "…변경될 수 있음", "확장형 선택 시…", 홀수층/짝수층 반전 안내 |
| 표제 | 세대 타입명·기본형/확장형·세대수 표기 | `(기본형)`, `(확장형)` 문자 h160~200, 세대수 `31세대` |
| 도곽 | 도곽 DWG/블록과 표제란 항목 | `X-SHEET`, `XR-FORM <프로젝트>`, `X-Sheet(건축)` |

## 절차

1. **실명**: 공간마다 정규 실명(zoning)으로 문자 생성. 위치 = 실 안목 영역에서 가구·기구·치수와 겹치지 않는 가장 큰 빈 사각형의 중심(후보를 격자로 탐색). 블록형 실명(`실명코드`)이 프로젝트 표준이면 그 블록에 속성으로 넣는다.
2. **면적**: finish 루프 면적으로 계산(벽 중심 기준 면적이 필요하면 walls axis 기준으로 따로 계산하고 어느 기준인지 표기).
3. **레벨·주기·표제**: profile 문구만 사용. 기존 도면 문구는 참고로만 보고 새 형상에 맞게 다시 쓴다.
4. **도곽**: 도곽 블록을 축척에 맞게 배치하고 세대 본체를 도곽 안에 놓는다. 기본형/확장형을 한 시트에 나란히 놓는 경우 같은 축척·같은 기준선.
5. 작도(`ann-001`…): `room.name`, `level`, `note`, `sheet`.

## 구현 상태

- 실명은 참고 세대 시트의 실명 좌표를 쓴다. 실명이 없는 공간은 config `extra_labels`로 다각형 중심에 둔다. 문자 스타일은 `layers.textstyle`, 높이는 120이다.
- 빈 자리 탐색 배치, 면적·레벨·주기·도곽은 미구현이다.

## 확인

- 실마다 실명 1개, 문자 bbox가 다른 객체와 겹치지 않음.
- 면적 합 = 세대 전용면적(기준 차이는 표기).
- `review.json.annotation`: 실명 목록, 겹침, 도곽 정보 미입력 항목.
