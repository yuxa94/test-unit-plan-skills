# 단열·결로방지

## 사용자가 정할 것 (`profile.insulation`)

| 항목 | 질문 예 | 관찰(참고만) |
|---|---|---|
| 방식 | 내단열 / 외단열? | 조사한 공동주택은 대부분 내단열(실내측) |
| 부위별 두께 | 외기직접, 외기간접(발코니·실외기실 접함), 세대간, 최상층/최하층 | 주기 `THK120`, `THK85`, `THK145`, `THK100`, `THK150` (지역·법규 기준에 따라 다름) |
| 재료 | 비드법보온판 2종1호 / 경질우레탄보온판 2종2호 / 압출법 … | P3, P6 일람표 |
| 결로방지 단열재 | 폭·두께·적용 위치 | `W450`(P1), `THK20`(P6), 외벽에 붙는 내벽·슬래브 단부 |
| 표현 | 반복곡선 심볼 / DASH 해치 / ANSI37 해치 | P2 `INSUL` 블록, A31 `insul1`, P4/P6 DASH s10, P5 ANSI37 s2 |
| 일람표 포함 | 단열 시공기준 표를 시트에 넣나? | P1, P3, P6 단열평면에 있음 |

두께 값은 심볼 크기나 해치 간격에서 추정하지 않는다(A31 `insul1` 삽입 축척 90/130은 표시 축척이지 두께가 아님). 법규 적합 판단은 하지 않는다.

## 부위 판정

`model.json` edges/spaces로 각 외곽 벽 면의 노출을 정한다.

| 벽 한쪽 | 다른 쪽 | exposure |
|---|---|---|
| 난방 실 | 외기 | `exterior_direct` |
| 난방 실 | 비난방 공간(발코니·실외기실·대피공간) | `exterior_indirect` (발코니측) |
| 난방 실 | 다른 세대 | `party_wall` (프로젝트 기준 확인) |
| 난방 실 | 코어(계단·EV홀) | 프로젝트 기준 확인 — 질문 |
| 비난방 | 외기 | 없음 |

## 절차

1. 단열이 붙을 벽 면(내단열이면 난방 실 쪽 면)을 따라 run을 만든다. run은 같은 exposure·두께가 이어지는 구간.
2. 개구부(문·창)에서 끊고, 끊긴 양 끝을 창틀/문틀 쪽으로 되돌림(return) 처리할지 프로젝트 확인. 모서리(L)는 이어서 하나의 run으로, T접합(내벽이 외벽에 붙는 곳)은 끊고 그 내벽 양면에 결로방지 단열재 구간(폭 W)을 둔다.
3. 단열층 형상: 벽 면에서 두께만큼 띄운 띠를 `rectunion.py`로 합쳐 외곽 루프를 만든다. 개구부 절단 사각형은 벽 두께가 아니라 **벽 두께 + 단열 두께**만큼 넓혀야 한다. 벽 두께만큼만 자르면 띠가 창 앞을 그대로 지나간다(청주 84A 사례). 실 쪽 마감선은 이 띠 바깥으로 이동해야 하므로 finish 스킬에 알린다(model.json `insulation_runs`).
4. 표현:
   - `repeat_curve`: 띠 중심선을 따라 반복곡선 블록(라이브러리 `insul1` 등)을 축척 1로 배열하거나, 곡선 폴리라인을 직접 생성. 블록을 띠 두께에 맞추려고 늘리지 않는다 — 맞지 않으면 사용자에게 표현 방식 확인.
   - `hatch_dash` / `hatch_ansi37`: 띠 루프에 해치.
5. 작도(`upc:run`, `ins-001`…): 띠 외곽은 `insulation`, 결로방지는 `insulation.dewproof`, 주기("THK120 단열재", 재료명)는 `note`.

## 구현 상태

- `run_reference_unit.insulation`
  - RC·조적 벽의 각 면을 400mm 간격으로 샘플링한다. 난방 실 쪽 면에만 단열 띠를 두고, 반대편으로 노출을 판정한다: 세대 밖 → 외기직접, 비난방 실 → 간접, 코어·샤프트 → core, `party_axes` → 세대간.
  - 띠는 `rectunion`으로 합치고, 벽과 개구부(단열 두께만큼 넓힌 절단)는 빼고 DASH 해치를 넣는다.
- 결로방지 단열재(폭)와 단열 일람표는 미구현이다(프로파일 폭 미정 시 보고).

## 확인

- 모든 `exterior_direct`/`exterior_indirect` 면에 run이 있는지(빠진 면 목록).
- run 끝이 개구부 또는 다른 run과 정확히 만나는지(틈 0).
- run 두께 = profile 값. 결로방지 구간 폭 = profile 값.
- `review.json.insulation`: 부위별 길이·두께, 미판정 면, 표현 방식.
