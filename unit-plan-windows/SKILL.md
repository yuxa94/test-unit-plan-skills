# 창호

## 사용자가 정할 것 (`profile.windows`)

| 키 | 뜻 | 청주 확정값 | 관찰(참고) |
|---|---|---|---|
| `rules[].room` | 창을 낼 실. 같은 실을 여러 번 적으면 창이 여러 개 | 84B 침실1은 S·E 두 개 | — |
| `rules[].side` | 실에서 벽 밖을 보는 방위, 도면 +y = N | 84A: 거실·침실 S, 주방·드레스룸 N / 84B: 주방 E | — |
| `rules[].width` | 창 폭(mm). 없으면 `widths` 중 (구간 − 600) 이하 최대값 | 3600, 1800, 1500, 1300, 1000 | 900~3900 |
| `rules[].type` | `double` / `single` / `outdoor_unit` | 거실·침실 double, 피난구 outdoor_unit | `WIN_이중창_*`, `실외기창_1000` |
| `rules[].facing` | `"exterior"`면 외기면만(발코니면 제외) | 피난구 | — |
| `widths` | 지정 폭이 없을 때 고를 목록 | [1000, 1500, 1800, 3600] | — |
| 창호부호 | 부호 형식·번호 체계 | 미정 | `창호기호`, `WINSYM-1`, `창-1800` |
| 확장형 처리 | 확장형에서 거실↔발코니 창을 외기 창으로 바꾸나 | 미정(기본형만 검증) | — |

## 규칙 (`scripts/place_windows.py` → `place_windows(model, rules, widths, taken)`)

1. **후보 벽**: 실이 한쪽에 있고, 반대쪽이 세대 밖(외기)이거나 비난방 발코니·서비스 공간인 벽 구간이다. `side`가 있으면 그 방위의 벽만 쓴다(실이 벽의 -y 쪽이면 바깥은 +y = N). `taken`(문·예약 구간)은 100mm 여유를 두고 뺀다.
2. **선택**: 가장 긴 빈 구간을 고르고, 창은 그 구간 가운데에 둔다.
3. **작도**: 창틀 외곽(벽 두께) + 유리선(이중창 2줄, 단창 1줄)을 그린다. 벽 몸체와 단열은 창 자리에서 끊는다. 단열은 단열 두께만큼 넓혀 자른다.
4. 결과에 `side`, `facing`, `width_mm`, `basis`를 남긴다. 지정 방위에 벽이 없거나 폭이 안 맞으면 미배치로 보고한다.

블록을 쓸 때는 블록의 anchor와 벽 면 대응을 먼저 측정한다. 맞는 블록이 없으면 직접 그리고 `authored: true`로 표시한다.

## 확인

- 모든 창이 외기·발코니 면 벽 위에 있음, 개구부 = 창 폭.
- 확장형/기본형 각각의 창 구성 차이를 표로 남김.
- 창호부호 목록(부호, 종류, 폭, 개수)을 `review.json.windows`에 기록 — 창호일람표 근거.

검증 이력과 근거: `unit-plan/references/validation-log.md`.
